# Data files

`india-pincodes.json`: pincode → `[district, state]` lookup used by the lead wizard.

- Source: https://github.com/saravanakumargn/All-India-Pincode-Directory (derived from the India Post pincode directory)
- License: MIT (see the source repository)
- Format: `{"302003": ["Jaipur", "Rajasthan"], ...}`, one entry per pincode (19,100 entries).
